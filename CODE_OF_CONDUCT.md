# Code of Conduct

Participation in this repository should remain constructive, technical and respectful.

Contributors should:

- discuss ideas and code rather than attacking people;
- provide actionable feedback;
- avoid harassment, discriminatory language and deliberate disruption;
- respect privacy and avoid publishing secrets or personal information;
- report security-sensitive material through an appropriate private channel.

Repository maintainers may edit, hide or remove contributions that materially violate these expectations.
