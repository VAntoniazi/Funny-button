# Security policy

Funny-button is a static browser experiment with no backend, authentication, persistence or server-side data processing.

## Reporting

If you identify a security issue in repository code or automation, open a private security advisory when available rather than publishing exploit details in a public issue.

For ordinary bugs, use the repository issue tracker.

## Scope

The external YouTube destination is outside this repository's security boundary. Repository automation should use the minimum GitHub Actions permissions required for each workflow.
